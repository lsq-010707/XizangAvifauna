ABOUT THIS PROJECT

基于证据，而非简单罗列

本项目以 AviList 2025b 分类体系为基础，评估西藏鸟类的可追溯记录。网站保留了原始证据说明及链接；未发现外链并不等于没有证据，记录状态以项目作者在名录中的评估为准。

OPEN & LIVING

让记录能够继续完善

所有物种信息都来自 GitHub 中的 Checklist.md。发现新证据或需要纠正记录时，可以前往项目仓库提出建议。 提交建议 ↗
